# PID - Projet Réservations

Projet réalisé dans le cadre du cours de Projet d'intégration de développement.

## Technologies utilisées

### Backend
- Java 21
- Spring Boot 4.1.1
- Maven

### Frontend
- Angular 21
- TypeScript
- Node.js
- npm

### Versioning
- Git
- GitHub

## Structure du projet

- `src/` : application backend Spring Boot
- `frontend/` : application frontend Angular
- `pom.xml` : configuration Maven
- `frontend/package.json` : dépendances du frontend

## Lancer le backend

Commande : `./mvnw spring-boot:run`

Adresse : `http://localhost:8080`

## Lancer le frontend

Depuis le dossier `frontend/` :

- `npm install`
- `npm start`

Adresse : `http://localhost:4200`

## État du projet

Itération 1 :

- installation de Spring Boot ;
- configuration de Maven ;
- installation d'Angular ;
- configuration de npm ;
- initialisation du dépôt Git ;
- publication du projet sur GitHub.
